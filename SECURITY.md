# Security Policy

> [!WARNING]
> **Project discontinued — this repository is no longer maintained.**
> `blender-ai-mcp` will not be developed further. It is being replaced by an entirely new and significantly better solution: much stronger 3D scene understanding, deeper and more reliable cooperation with Blender, far better workflow control, and more. The new add-on will be released soon.

## Supported Versions

No versions of `blender-ai-mcp` are supported. No further security fixes, patches, or releases will be made for this project.

| Version | Supported |
| ------- | --------- |
| All releases | No |

If you continue to run the archived code, do so at your own risk and review it for your own environment.

## Reporting a Vulnerability

Because the project is discontinued, vulnerability reports will not result in fixes or new releases for this repository. Please **do not** open a public GitHub issue for security vulnerabilities.

If you believe a vulnerability is relevant to the upcoming replacement add-on, you may still report it privately:
- Email: `patryk.ciechanski@patrykiti.pl`

Include a clear description of the impact, steps to reproduce, and environment details (with any secrets removed).
