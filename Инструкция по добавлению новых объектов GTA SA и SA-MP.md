# Добавление новых объектов в GTA San Andreas и SA-MP

## Важно

SA-MP 0.3.7 не поддерживает масштабирование объектов командами сервера. Чтобы получить объект другого размера, необходимо создать отдельную DFF-модель.

Для локальной сборки надёжнее заменять существующий, но неиспользуемый ID SA-MP. Добавление модели на закомментированный или несуществующий ID может работать в Map Construction, но сервер SA-MP такой объект не создаст.

Все игроки, которым нужно видеть новый объект, должны установить одинаковые модели и IDE-файлы.

## Необходимые программы

- Blender с DragonFF для импорта и экспорта DFF.
- `GTA-SA Crazy IMG Editor.exe` либо другой редактор IMG-архивов.
- Текстовый редактор для IDE и серверной карты.
- Map Construction для проверки объекта.

## 1. Сделать резервные копии

Перед изменениями сохранить:

```text
GTA San Andreas\SAMP\SAMP.img
GTA San Andreas\SAMP\SAMP.ide
GTA San Andreas\modloader\SAMP\SAMP.img
GTA San Andreas\modloader\SAMP\SAMP.ide
GTA San Andreas\modloader\models\gta3.img
GTA San Andreas\models\gta3.img
```

Перед редактированием полностью закрыть GTA SA, SA-MP и Map Construction.

Используемый в рабочей конфигурации IMG-редактор:

```text
D:\02_GAMES\Моды и софт GTA SA\GTA-SA Crazy IMG Editor\GTA-SA Crazy IMG Editor.exe
```

В редакторе следует заменять существующую запись с нужным именем и перестраивать архив. Нельзя добавлять вторую одноимённую запись.

## 2. Извлечь исходную модель

1. Найти model ID исходного объекта в Map Construction.
2. Найти соответствующую строку в IDE-файлах.
3. Определить имя DFF и TXD.
4. Извлечь DFF из нужного IMG-архива.

Пример для ID 1327:

```text
1327, junk_tyre, junk, 40, 128
```

Здесь:

- DFF: `junk_tyre.dff`
- TXD: `junk.txd`
- исходный ID: `1327`

## 3. Изменить размер в Blender

1. Импортировать DFF через DragonFF.
2. Выделить все части модели.
3. Установить одинаковый Scale по X, Y и Z.
4. Для уменьшения вдвое использовать `0.5`.
5. Применить трансформацию через `Ctrl+A` → `Scale`.
6. Проверить положение origin и иерархию объектов.
7. Экспортировать модель через DragonFF в новый DFF.

Пример имени:

```text
JunkTyreHalf.dff
```

Не изменять исходный DFF, если в игре нужны оба размера объекта.

## 4. Выбрать рабочий ID

Не следует использовать закомментированный ID только потому, что он отображается в Map Construction. Такой объект может показываться в редакторе, но не создаваться сервером.

Надёжный вариант:

1. Найти существующий ID SA-MP, который не используется проектом.
2. Заменить его модель своей.
3. Проверить поиском, что ID отсутствует в серверных `.pwn`, `.inc` и файлах карты.

В текущей сборке для маленького колеса использован ID `19300`, ранее содержавший `blankmodel`.

## 5. Добавить DFF в SAMP.img

Модель должна находиться в архивах, которые реально загружают Map Construction и игра:

```text
GTA San Andreas\SAMP\SAMP.img
GTA San Andreas\modloader\SAMP\SAMP.img
```

Если используется Mod Loader, ориентироваться на `modloader\modloader.log`. Строка вида:

```text
Opening file for streaming "modloader\samp\samp.img"
```

означает, что игра использует архив из Mod Loader вместо корневого архива.

При замене существующего ID имя DFF в IMG должно совпадать с именем модели в IDE.

Для ID 19300 рабочая запись имеет имя:

```text
blankmodel.dff
```

В эту запись помещается содержимое уменьшенного DFF.

## 6. Изменить SAMP.ide

Изменить строку выбранного ID в обоих файлах:

```text
GTA San Andreas\SAMP\SAMP.ide
GTA San Andreas\modloader\SAMP\SAMP.ide
```

Пример:

```text
19300, blankmodel, junk, 40, 128
```

Формат строки:

```text
ID, имя_DFF_без_расширения, имя_TXD_без_расширения, дальность_отрисовки, флаги
```

Если используется текстура исходного объекта, новый TXD создавать необязательно. В примере маленькое колесо использует существующий `junk.txd`.

## 7. Обновить серверную карту

В файле карты заменить временный ID на рабочий существующий ID.

Пример:

```pawn
CreateObject(19300, 2415.72168, 88.13407, 25.88610, -2.58002, -89.76006, 0.00000);
```

Исходные большие колёса могут продолжать использовать ID `1327`:

```pawn
CreateObject(1327, 2416.54614, 96.77846, 25.46828, 2.33999, 89.27998, 3.12000);
```

После изменения карты перезапустить сервер или перезагрузить систему загрузки объектов.

## 8. Проверить результат

1. Полностью закрыть Map Construction, GTA SA и SA-MP.
2. Запустить Map Construction заново.
3. Проверить новый ID.
4. Закрыть редактор.
5. Запустить сервер и SA-MP заново.
6. Телепортироваться к координатам объекта.
7. Проверить оба размера и вращение.

## Диагностика

### Красный маленький квадрат

IDE-строка найдена, но DFF отсутствует в архиве, который читает Map Construction.

Проверить корневой:

```text
SAMP\SAMP.img
```

### Объект виден в Map Construction, но отсутствует в игре

Возможные причины:

- Использован закомментированный или несуществующий model ID.
- Сервер не принимает выбранный ID.
- Игра загружает другой IMG через Mod Loader.
- `modloader\SAMP\SAMP.ide` отличается от корневого `SAMP\SAMP.ide`.
- Сервер или клиент не были полностью перезапущены.

### Игра показывает старую модель

Проверить `modloader\modloader.log`. Если там указан другой архив, править нужно именно его.

Например:

```text
Opening file for streaming "modloader\models\gta3.img"
Opening file for streaming "modloader\samp\samp.img"
```

### Модель белая или без текстуры

- Неправильное имя TXD в IDE.
- TXD отсутствует в активном IMG.
- Материалы DFF ссылаются на другие имена текстур.

### Модель отображается, но коллизия неправильная

Масштабирование DFF не всегда масштабирует COL. Необходимо отдельно изменить коллизию либо использовать объект без коллизии и создать вспомогательные невидимые коллизионные объекты.

## Итоговая схема текущего маленького колеса

```text
Исходный объект: 1327, junk_tyre
Большие колёса: ID 1327
Маленькие колёса: ID 19300
Модель ID 19300: уменьшенный junk_tyre
Текстуры: junk.txd
Масштаб: 0.5
```
